# 剑鱼标讯 MCP

把剑鱼标讯的 MCP 数据服务接入 DSH。插件激活时通过 MCP 管理器注册一个托管服务器，服务端的工具会以 `mcp__<命名空间>__<工具名>` 出现在对话中（默认命名空间 `jianyu`）。

## 功能

- 在 **设置 → 内置插件 → 剑鱼标讯 MCP** 标签里填写 **服务地址** 和 **API Key**，保存后立即重连，无需重启 DSH。
- 保存修改会热更新运行中的配置；禁用或卸载插件即卸载该 MCP 服务器，已注册的工具随之移除，不影响其他插件或已配置的 MCP。
- API Key 留空时回退读取环境变量（默认 `JIANYU_MCP_TOKEN`），便于不想把密钥写进配置的部署。
- 未配置 API Key 时不注册服务器，避免出现只会报鉴权失败的工具。
- 内置默认地址指向剑鱼标讯 MCP 数据服务，可在设置页覆盖为其他兼容 MCP 的地址。

## 配置项

| 字段 | 默认值 | 说明 |
|---|---|---|
| `url` | `https://jyaiopen.jianyu360.cn/mcp` | MCP 服务地址（streamable-http），可在设置页修改 |
| `token` | 空 | 剑鱼开放平台 API Key，作为 `JianYu-Api-Key` 请求头发送；设置页以密码框写入、从不回显；留空则读环境变量 |
| `serverName` | `jianyu` | 工具命名空间，影响工具名 `mcp__jianyu__…`；普通字段，修改需重载插件 |
| `tokenEnv` | `JIANYU_MCP_TOKEN` | 令牌留空时读取的环境变量名 |
| `startupTimeoutMs` | `30000` | 连接与初始工具发现的超时（毫秒） |

## 使用步骤

1. 安装并启用本插件。
2. 打开 **设置 → 内置插件**，在标签行选择 **剑鱼标讯 MCP**。
3. 确认服务地址，填写 API Key（或设置 `JIANYU_MCP_TOKEN` 环境变量后留空）。
4. 点 **保存**；插件热更新配置并重新连接 MCP 服务，工具出现在模型的工具列表里。
5. 验证连接：在对话里让模型调用一个 `mcp__jianyu__*` 工具（例如查询余额或搜索标讯）；能返回结果即表示地址与 API Key 均有效。

## 限制

- 令牌以 secret 字段保存在当前 profile 的配置文件中（设置页掩码，不回显）；如需避免落盘，请改用 `tokenEnv`。
- 数据访问范围由服务端令牌权限决定，插件只负责连接。
- 服务不可达或令牌无效时，连接可能进入失败/重试状态，工具暂不可用；修改配置会触发热重连。
- 一个插件实例只注册一个服务器；需要同时接多个剑鱼 MCP 服务时，分别安装配置不同 `serverName` 的副本。
