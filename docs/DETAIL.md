# 剑鱼标讯

在对话里直接查招标采购数据。装好、填上密钥，就能像问同事一样问它：哪有项目、预算是多少、甲方之前招过什么。

## 它替你省掉什么

平时找项目，得打开网站、选地区、选行业、选时间、翻好几页、再把关键信息抄到表格里。用这个插件，这些步骤变成一句话：

- 「最近一周河南有哪些医疗设备招标？」
- 「这家单位今年招过什么，预算大概多少？」
- 「陕西最近有没有要开工的产业园项目？」
- 「这条公告的中标结果是什么？」

它会去剑鱼的数据里查，然后把项目名、地区、金额、采购单位、发布时间整理成清单给你；要看原文，接着问就行。

## 三种最常用的用法

**找当周的活儿**
带上地区、行业、时间、金额，一次筛干净：「这周江苏 500 万以上的市政工程，还没截止的」。

**摸清一个甲方**
按采购单位名直接问，能看到它过去招过什么、大概什么量级，比第一次见面就打电话强得多。

**提前占位**
拟在建项目比招标公告早一步。别人还在等公告，你已经知道哪个园区要开工、业主是谁。

## 三步配置

1. 安装并启用插件。
2. 打开 **设置 → 内置插件 → 剑鱼标讯**，把剑鱼开放平台给你的密钥粘进去，点保存。地址默认就指向剑鱼，不用改。
3. 回对话框问一句试试，比如「今天还能查多少额度」，能返回数字就说明通了。

保存后立即生效，不用重启 DSH；以后换密钥也在这里改。

## 花多少钱

- 查余额、查消耗记录：免费。
- 搜索标讯、搜索拟在建项目、查看详情：按次消耗剑鱼币。和你平时在剑鱼网站用的是同一个账户、同一份余额。
- 余额不足时会直接告诉你，按提示充值后接着用。

## 关于数据

- 只读：不发消息、不改数据、不下单，做什么都只是查询。
- 联系人、电话由服务端统一脱敏，显示「请前往剑鱼官网查看」，插件不会去还原。
- 能查到哪些数据，取决于你这个密钥在剑鱼开放平台的权限。
- 密钥只保存在你自己的电脑上，界面上以密码框显示，保存后不再显示原文。

## 遇到问题

**连接不上，或者提示密钥无效**
先确认密钥在剑鱼开放平台还有效、账户余额够，然后在设置页重新粘一次、保存。保存会自动重连。

**搜出来的结果不够准**
关键词收短一点，地区用整省，时间放宽，行业和采购单位类型可以再叠加。两三个词的关键词组合通常最好用。

**设置页看不见了**
插件被禁用或卸载时，设置页和这些查询工具会一起消失，重新启用即可。

## 附：给技术同学的说明

- 需要 DSH `>=0.2.2-rc.1 <0.3.0-0`、Node.js 20 以上。
- 密钥存放在当前 profile 的配置里（secret 字段，掩码显示），不想落盘可以留空并改用环境变量 `JIANYU_MCP_TOKEN`。
- 一个插件实例注册一个 MCP 服务（默认命名空间 `jianyu`，工具名形如 `mcp__jianyu__*`）。要同时连多个剑鱼服务，装多份并改 `serverName`。
